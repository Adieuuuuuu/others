LIJIANG · SHANGRI-LA · MEILI

3天2晚包车纯自然风光行程

适配：首日中午丽江古城出发、放弃松赞林寺/普达措、最后一晚20:00丽江三义机场航班

总览前置提醒D1D2D3景点清单小贴士

行程定位

全程走G214滇藏线，包车可随停随拍，只逛峡谷、江河、草原、雪山自然景观，节奏可控，精准卡点航班，零误机风险。

前置时间提醒（包车优势）

1. 20:00航班，国内航班起飞前40分钟停止值机，预留堵车冗余，18:00前抵达机场；古城打车到机场45分钟，返程日预留充足缓冲。
2. 本地熟路包车司机，山路弯道驾驶稳，赶路效率高于自驾，沿途观景灵活停靠。

D1 第一天（午间出发）

丽江古城 → 长江第一湾 → 虎跳峡（上虎跳）→ 小中甸牧场 → 香格里拉独克宗 【住宿：香格里拉市区】
车程分段游玩，不赶夜路
12:00 古城用餐完毕

1. 12:00 古城用餐完毕，行李装车正式出发

13:00 长江第一湾观景台

2. 13:00 停靠长江第一湾观景台，远眺金沙江大拐弯，免费拍照15分钟

13:40 虎跳峡

3. 13:40 抵达虎跳峡，走平缓开发栈道游玩1.5小时，近距离感受金沙江撞击虎跳石的峡谷巨浪风光

15:30 前往香格里拉

4. 15:30 出发前往香格里拉，沿路边走边停：远眺哈巴雪山、藏式村寨，6-8月打卡小中甸花海牧场，野花遍地牛羊成群，公路随停拍摄高原草甸风光

18:00 香格里拉独克宗

5. 18:00 抵达香格里拉，闲逛独克宗古城广场，看本地人跳锅庄，吃牦牛肉火锅/尼西土锅鸡，适应3300米海拔，全程无收费人文寺院景点

D2 第二天

香格里拉 → 纳帕海环湖 → 奔子栏 → 金沙江月亮湾 → 白马雪山垭口 → 飞来寺 【住宿：飞来寺雪山观景酒店】
全天沿江翻越雪山，一路皆是世界级自然风光，包车边走边玩，总车程3.5-4.5小时
08:30 纳帕海·依拉草原

1. 08:30 香格里拉出发，走免费环湖公路逛纳帕海·依拉草原，雨季打卡水上公路，旱季驰骋草甸湿地，看水鸟成群，游玩1小时，不进私人收费草场

10:30 奔子栏

2. 10:30 抵达茶马古道河谷重镇奔子栏，午饭休整，干热河谷风光开阔

11:30 金沙江大拐弯（月亮湾）

3. 11:30 打卡金沙江大拐弯（月亮湾），俯瞰Ω形江水盘旋群山，三江并流奇观，观景台停留20分钟拍照

12:30 白马雪山垭口

4. 12:30 翻越白马雪山垭口（4292m），建议走老路垭口，经幡白塔环绕，远眺连绵积雪山峰，夏季高山杜鹃盛放，短暂下车打卡15分钟，不走隧道错过核心山景

16:00 飞来寺

5. 16:00 抵达飞来寺，优先去雾浓顶观景台，拍摄梅里十三峰全景，傍晚坐等雪山日落晚霞，入住观景房，推窗直面神山，静待次日日照金山

D3 第三天

飞来寺日照金山 → 原路返程丽江 → 20:00航班
时间精确排布，兼顾观景+稳妥赶飞机，包车司机全程把控车速
6:30-7:30 梅里日照金山

1. 6:30-7:30 观景台守候梅里日照金山，卡瓦格博主峰被朝阳铺满金光，看完立刻动身返程（8:00准时出发，不拖沓）

返程沿路回看风光

2. 返程沿路回看白马雪山、月亮湾、纳帕海风光，喜欢的点位短暂停靠拍照，全程包车顺畅行驶

14:00 抵达丽江古城

3. 14:00 抵达丽江古城，取回行李，简单用餐闲逛

15:15 前往三义机场

4. 15:15 从古城出发前往三义机场，16:00左右到达机场，值机、安检后有大把空余时间休息，从容等候20:00起飞航班，时间非常宽裕

沿途顺路自然景点完整清单

沿途顺路自然景点完整清单（全程避开人文寺庙、森林公园）

去程顺序：长江第一湾 → 虎跳峡峡谷 → 小中甸草原花海 → 纳帕海湿地草原 → 奔子栏河谷 → 金沙江月亮湾 → 白马雪山 → 梅里雪山（飞来寺/雾浓顶）

返程重复打卡沿线江景、雪山草甸，无需额外绕路。

长江第一湾虎跳峡峡谷小中甸草原花海纳帕海湿地草原奔子栏河谷金沙江月亮湾白马雪山梅里雪山

包车出行小贴士

1. 车型：4人内优先5座SUV，底盘高走山路更稳；多人可选7座商务车，空间舒适
2. 路况：G214多盘山弯道，雨季留意落石提示，司机熟悉路况会规避拥堵路段
3. 物资：飞来寺、白马雪山垭口风大温度低，带防风厚外套，全程高倍防晒、多喝水，不要剧烈跑动
4. 虎跳峡只走上虎跳开发栈道，安全省力，不建议走未开发中虎跳野路
5. 日照金山10月-次年5月晴天概率更高，夏季雨季云雾多，飞来寺住一晚大幅提升观赏概率
6. 全程纯玩无购物，和包车司机提前约定只停靠自然观景台，不进消费点位。
