# 排队提醒 Android App

纯本地 Android APK：在内置 WebView 中登录大众点评，保存本地 Cookie，从页面文字中识别“前方还有多少桌”，并把最新进度持续显示在 Android 常驻通知中。

## 1.1 实时监控

1. 网页自身主动更新时，通过页面变化监听和每秒读取，约 1 秒内同步最新桌数。
2. 网页自身不更新时，应用自动刷新页面：普通阶段约 10 秒一次，接近提醒阈值时约 4 秒一次。
3. 不再需要设置刷新间隔，只保留“还有多少桌时提醒”。
4. 达到提醒条件后发送高优先级提醒，但继续监控并更新常驻通知。
5. Cookie、链接和状态仅保存在手机本地，不需要业务服务器。

## 限制

- 实际新鲜度仍受大众点评服务器和排队页面的数据更新时间影响。
- 某些手机的省电策略可能杀死前台服务，需要将应用设为“不限制”或允许后台活动。
- 页面结构变化后，文字识别规则可能需要调整。
- APK 为个人侧载测试版本，不用于应用商店分发。
