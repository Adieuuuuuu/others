# 排队提醒 Android App

纯本地 Android APK：在内置 WebView 中登录大众点评，保存本地 Cookie，使用前台服务定时刷新排队页面，从页面文字中识别“前方还有多少桌”，达到阈值后发送本地通知。

## 第一版功能

1. 粘贴 HTTPS 排队链接。
2. 在应用内完成短信登录。
3. 手动检测当前页面是否能识别桌数。
4. 设置提醒阈值和刷新间隔（默认 10 桌、10 分钟）。
5. 常驻通知显示监控状态，可立即检查或停止。
6. 达到阈值、登录失效时发送高优先级通知。
7. Cookie、链接和状态仅保存在手机本地，不需要业务服务器。

## 已知限制

- 大众点评页面结构变化后，文字识别规则可能需要调整。
- 某些手机的省电策略可能杀死前台服务，需要将应用设为“不限制”或允许后台活动。
- 第一版优先读取网页 DOM 文本，尚未加入截图 OCR。
- APK 为个人侧载测试版本，不用于应用商店分发。

`generated/` 中的压缩源码会在 GitHub Actions 构建时还原为 Java 文件。完整可读源码同时保存在交付的源代码压缩包中。
